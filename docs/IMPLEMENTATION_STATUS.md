## M00 — Discovery and setup

**Findings**
- Repository contained only the build plan (`Master-Plan.MD`). No existing
  code, framework or seamless-texture tool. A formatted copy of the plan lives
  at `docs/MASTER_BUILD_PLAN.md`.
- Owner has created an R2 bucket and a Supabase project linked to GitHub
  (2026-10-16). Credentials have not been shared and should not be pasted into
  chat; they go into host environment variables at deploy time.
- Owner has local textures, models and a seamless texture tool; integration
  pending delivery of a sample pack and the tool source.

**Built**
- Next.js 16.4.2 + React 19.3 + TypeScript 5.9 (strict), Tailwind CSS 4.3,
  ESLint 9 flat config (`eslint-config-next`), Vitest 4, Playwright 1.56.1
  (matches the pre-installed Chromium), pnpm 10, Node 22.
- Initial design tokens and type scale (replaced in M01, see ADR 0007).
- `/api/health`, E2E server harness (`scripts/e2e-server.ts`).
- GitHub Actions CI: lint → typecheck → unit/integration (with a Postgres 16
  service) → build → Playwright.
- Docs: architecture, design system, ADRs 0001–0006.

**Verified**: PGlite supports roles, `SET LOCAL ROLE`, RLS policies,
`set_config`, full-text search, `pg_trgm`, array and JSONB parameters — the
basis for ADR 0002. A local Postgres 16 server is used for driver tests.

**Toolchain notes**
- TypeScript 7 (native port) is the npm `latest` but is pinned to 5.9 for
  Next.js/typescript-eslint compatibility.
- Next.js 16 removed `next lint`; `pnpm lint` runs ESLint directly.
- `pnpm typecheck` runs `next typegen` first so `PageProps`/`LayoutProps`
  globals exist.

## M01 — Public shell and design system

**Built**
- Design system matched to the owner's **11AM-Seamless** tool (ADR 0007):
  monochrome tokens, IBM Plex Mono + Share Tech Mono, CRT overlay with an
  on/off switch, ASCII banner. Documented in `docs/DESIGN_SYSTEM.md`.
- UI primitives (`src/components/ui`): buttons, ON/OFF, fields, prompt input,
  select, checkbox, toggle, ASCII slider, segmented control, drag-to-scrub
  number field, colour field, badges, dialog, menu, tabs, tooltip, toast,
  ASCII progress, empty/error/notice states, pagination, table, dropzone,
  breadcrumbs (with BreadcrumbList JSON-LD), panel, pipeline module, advanced.
- Site shell: sticky header with a Tools mega menu, mobile drawer, Cmd/Ctrl+K
  and `/` search palette (static index plus `/api/search`), CRT switch, footer
  with system clock, skip link, 404, error boundary, global error, loading
  skeleton.
- Pages: home (banner, telemetry, library search, pipeline, VRAM-style texture
  page with texel readout, tools list), tools index, section holding pages for
  Assets/Textures/Collections/Shaders/Starter projects/Learn/Creators/Resources,
  About, Licences, Privacy, Terms, Contact & takedowns.
- SEO base: metadata templates, canonical URLs, `robots.txt`, `sitemap.xml`,
  SVG icon.
- Deterministic, tileable procedural demo textures (11, CC0) in
  `public/demo/textures`, regenerated by `pnpm demo:generate`.
- Processing core started: RGBA image type, seeded PRNG/noise, Bayer matrices
  and ordered posterise (tested).

**Verified**: lint, typecheck, unit tests (35), production build, Playwright
(25: navigation, mega menu, search palette keyboard flow, CRT toggle
persistence, skip link, 404, robots/sitemap, mobile drawer, no horizontal
overflow at 390px, axe audits). Screenshots reviewed at 1440px and 390px.

**Known limitations**
- Section pages other than Tools are honest holding pages until M03/M06.
- Legal page copy is a starting draft for the owner to review before launch.
